# 繁体中文の任意言語パック

本体は日本語だけで動きます。このフォルダを本体ルートの `langpacks/zh-TW/` に置き、`HUB_LANG=zh-TW` で起動した時だけ使います。別の場所に置く場合は `HUB_LANGPACK_DIR` にこのフォルダの絶対パスを指定します。変更後はHubを起動し直してください。

パックがない時や読み込めない時は日本語で動きます。訳がない文も日本語になります。`pack.json` の `verifiedWith` は最後に検証した本体の版で、版が違っても読み込みを拒否しません。

`ui.json` は画面、`backend.json` は本体の文言、`native.json` はMacアプリの文言です。4.126.41 の画面・メッセージへの追加訳を保持し、4.126.42を対象に自動確認しています（下記の製品側制約が残ります）。`docs/` の中国語文書は凍結しており、本体の更新ごとに書き換える必要はありません。

通常の開発では `npm --prefix hub test` を使います。パックを更新・利用する時は `npm --prefix hub run test:langpack` を実行します。未翻訳は警告になり、`HUB_I18N_STRICT=1` を付けると失敗になります。翻訳付き自動更新は、この厳格なパック試験も実行します。

中国語見出しの既存の台帳・作業ファイルを読む互換機能は、本体に残しています。言語パックは設定画面からフォルダを選んで追加できます。公開・自動配信はこの正本の準備とは別です。

音声入力のお知らせとボタンの説明も辞書を使います。認識言語は日本語（`ja-JP`）のままで、表示言語を変えても変わりません。音声の自動確認は隔離Chromeの模擬認識で、実マイク・Windows・iPhoneでの確認ではありません。

Mac辞書は用途説明2件・更新復旧5件を含む53件が登録済みで、今回も保持しています。ソース用Mac窓の翻訳関数で参照する文には適用できますが、別の配布用窓（hub/staging-app/Window.swift）は固定の日本語を使い、配布アプリの用途説明も日本語のままです。`verifiedWith` は互換性を確認した版で、Macの全表示を翻訳済みという意味ではありません。

今回の追加は画面141件・本文5件です。既存訳とMac辞書は変更していません。抽出は UI.text/message の文字列と条件分岐、UI.html/template、本文の lt、Macの tr を対象とし、画面全体の翻訳を保証するものではありません。

4.126.42では製品側の送信ボタンを翻訳に接続し、「送る／Museへ送る（外部）」に既存訳が適用されます。辞書は4.126.41の内容を保持しています。

製品側の制約：テンプレートへ差し込む値は自動翻訳されないため、Museの状態・操作の一部は日本語が残ります。UI.textを通るMuseの結果通知には辞書が適用されますが、返答待ち欄・保存済みイベント・翻訳処理を通らないエラー通知は原文表示です。繁體中文の画面試験で残っていた送信ボタンの失敗は4.126.42の製品修正で解消しました。試験の期待値は変更していません。

4.126.44では左一覧の検索欄に6件の訳を追加し、精簡化した検索欄へ適用します。既存訳は保持し、verifiedWithは4.126.44です。
