# Project Hub 正式配布候補 4.125.2

配布用の発行者証明書とMac公証を使わない直接配布の確認候補です。Macのローカル封印は保持していますが、Appleが発行元や安全性を確認したものではありません。本番受付・安定版更新の公開は未完了です。Mac・Windowsとも本番の体験・購入・利用コードの受付先を設定済みですが、サーバー側の設定・正式buildの登録確認と実機確認が別途必要です。購入試験版のコード・購入証明は使えません。

## 起動前

- Mac：Apple Silicon、macOS 13以降、Node.js 22.13以降、Git。Windows：Windows 11 x64、Node.js 22.13以降、Git for Windows、Windows PowerShell 5.1、WebView2 Runtime。
- AIを使う場合は契約済みCLIを別途用意します。Hubの購入にAI利用料は含みません。API従量課金の設定は不要です。
- 以前のHubは処理・保存を終えて終了してください。同時に開かないでください。
- Macは固定したアプリの場所から起動します。Windowsの作成用一式には固定実行ファイルがまだありません。配布担当が同梱 docs/project-hub/RELEASE-OPERATIONS.md の手順で MAKE-WINDOWS-APP.cmd を一度実行し、作成・全件照合を終えた別フォルダ（末尾 -publisher-free）だけが起動用候補です。その全体を展開して START-WINDOWS.cmd を通常起動します。管理者実行は不要です。アプリ起動中のコンパイルは行いません。
- Windowsの作成用一式と起動用完成版を取り違えないでください。固定ファイルのSHA照合は内容一致の検査で、発行元の証明ではありません。

## OSの警告が出た場合

公式配布元と対象ファイルのSHAを確認した場合だけ進めます。配布用証明書・Mac公証がないため警告が出たり、端末の保護設定によって起動できなかったりします。

- Mac：一度起動を試した後、［システム設定］→［プライバシーとセキュリティ］に対象アプリの［このまま開く］が表示される場合に限り、そのアプリだけを許可できます。破損・悪質な内容の警告なら停止し、表示を担当へ伝えてください。
- Windows：SmartScreenの［詳細情報］→［実行］が表示され、入手元と内容を確認できる場合に限り進めます。Smart App Controlや組織の制限で起動できない場合、この配布方法では利用できません。保護全体の無効化や組織の制限回避は案内しません。

公式資料：[Apple](https://support.apple.com/ja-jp/102445)、[Microsoft SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)、[Smart App Control](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)。表示を確認できない場合は無理に進めず担当へ知らせてください。

## データの保存先

［設定］→［管理］→［データの保存先］で、Productが入った以前のAI-Workspaceを選びます。標準は［書類］内のAI-Workspaceです。別の場所もフォルダ選択・手入力で指定できます。

［内容を確認］で場所・プロジェクト名・自由対話を確かめてから確定し、終了・同じアプリの再開で切り替えます。新規の場合は空のフォルダを作って選び、再開後に［＋ 新しいプロジェクト］から始めます。選択した場所へ直接読み書きし、元へ戻すコピーは不要です。以前の実行待ちや自動AI・自動整理は勝手に再開しません。

購入情報・端末の鍵・登録結果・更新記録の保護領域は、Macでは ~/Library/Application Support/ProjectHub、Windowsでは ~/ProjectHub です。試験用ProjectHub-Purchase-Test-v1とは別です。試験中に作った内容も削除しません。別の保存先の内容は自動合流しません。

以前の正式版の利用権が一般保存先にある場合は、元を変えず、同じOSアカウントの鍵と正式な証明を通常処理で検証して保護領域へ引き継ぎます。不明・不正・途中失敗は停止し、鍵の作り直しや試験証明の昇格はしません。エラーなら購入・登録を繰り返さず担当へ知らせてください。

## 無料体験と購入

本番の体験受付が有効になった後は、確認済みの発行時刻から30日です。体験中の確認が取れたアプリ内購入は税込1,100円、通常は税込4,900円です。満了後は有料機能が制限されます。保存データは削除しません。保留・通信・鍵・時計エラーの表示は期限切れと区別してください。

購入はブラウザで行い、完了画面の利用コードをアプリの［利用コード］に入力します。購入済み表示を確認してください。支払済み・結果不明・登録エラーなら再購入・再登録せず、表示文と版・OSだけを問い合わせへ伝えてください。コード・鍵・カード情報・購入証明・個人の会話は送らないでください。

## 更新と復旧

Macの新しい画面部品に対応する安定版更新情報は project-hub-runtime-update-mac-shell2.json、Windowsは project-hub-runtime-update-windows.json です。旧Mac用 project-hub-runtime-update.json には新しいruntimeを配信しません。旧方式の配信先や購入試験版の配信先とは別です。署名と公開が揃うまでは取得に失敗し、現在の版を保持します。

新版を適用した後は保存・処理の終了を待ち、同じアプリを閉じて開き直します。未保存入力の確認では、取り消すと更新せず下書きを保持します。新版の健康確認ができなければ前の版へ戻します。一般データ・購入情報を更新ファイルで置き換えません。

Macの4.126.41など旧版からは自動更新せず、処理と保存の完了後に通常終了し、最新版ZIPの「Project Hub.app」全体を使います。アプリの中身だけをコピーしないでください。初回起動時は以前の適用済み・保留中のruntimeを選ばず、新しいアプリ内のruntimeを使います。古い更新記録は控えとして残り、会話・保存先・購入情報・ダウンロード済みの版は消しません。移行後は同じ新しいアプリを使い、旧アプリを再び開かないでください。Windowsの手動更新も通常終了後に配布一式全体を入れ替えます。起動不能・版が戻る・署名エラー時は更新状態を削除せず、表示を担当へ知らせてください。
