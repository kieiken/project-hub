# Project Hub の変更の記録

新しいものが上。更新するたびに `package.json` の version と、ここの一番上を同じ番号にする（テストで確かめる）。
番号の付け方：大きな作り直し＝1つ目、機能を足した＝2つ目、直しただけ＝3つ目を上げる。

## 4.70.0 — 2026-10-07

- Mac の読み取り確認に現在の Hub 作業場所と、明示的に選ぶ外部1フォルダを追加。「ファイルとフォルダ」を案内し、確認だけではファイル・AI の書き込み範囲・稼働中の本体を変更しない。

- Codex・Claude の会話を選んでリンクする画面を追加。最初はすべて未選択で、件数・足りない記録・注意を確認してから元の記録へのリンクだけを保存。元の会話・コード・作業フォルダを移さず、コピーや Hub の新しい作業を作らない。
- ［外部の会話］から同じ元の会話 ID／thread ID で再開し、既存のログインと権限を使って元の履歴へ新しい番を保存。許可・停止・送信の重複防止に対応し、元の記録が使えない時は別の会話を作らない。元のアプリの即時画面更新は保証せず、開き直して同じ記録を読む。
- Hub に依存しない AI Session Exporter のライブラリ・CLI・ローカル画面を公開用に用意し、明確に選んだ人と AI の文字だけを JSON／Markdown へ出力できる。
- Hub の会話・ターミナルの書き込み先を実際の作業フォルダと同プロジェクトの台帳へ限定。Claude は `acceptEdits`、Codex は `workspace-write` を使い、古い広い許可指定を起動時に絞る。元のコード・参照フォルダは追加の書き込み先にせず、リンクした元の会話は元の道具の権限を保つ。
