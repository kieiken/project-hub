# Project Hub の変更の記録

## 4.125.1 (2026-10-21)

- Claude Code がログアウト状態の時、設定のAIアカウント欄が「ログイン状態を確認できませんでした」ではなく未ログインと表示されるように直しました。`claude auth status --json` は未ログインでも正しいJSONを出したうえで終了コード1を返すため、これまで内容を読んでいませんでした。
- 終了コードだけの失敗で `loggedIn:false` の時に限って読みます。CLIが見つからない・時間切れ・シグナルでの停止・読めない出力・終了コード付きのログイン済み表示は、従来どおり不明のままです。

## 4.125.0 (2026-10-19)

- Windows更新の検査で、専用窓の実行ファイルと3つのライブラリに記録されるWindowsの権限値を受け付けるようにしました。対象の場所と値を限定し、中身の照合・Macの権限検査は維持します。

- Windows専用窓の実行ファイルと窓に、Mac版と同じ絵柄のアプリアイコンを設定しました。大小の表示用画像を同梱し、作成時と返却時の入力照合にも含めます。

- Windows専用窓は起動後に上部の保存先表示欄を隠し、アプリ画面を広く使うようにしました。起動中とエラー時の案内は引き続き表示します。

- 正式配布候補4.125.2では、Windowsの体験・購入・利用コードの受付先をMacとそろえました。同じ保存済みソースから両OSの候補を作ります。本番サーバーの設定・版登録、実機確認、安定版公開は別途必要です。

- 利用コードの拒否応答・通信失敗・読み取れない応答を区別し、内部のエラー文を表示せず固定の案内にしました。受付準備中・利用権引継ぎの保留案内は維持します。古いコードの有効性を変える修正ではありません。

- 本作業の統合候補に、設定・作業画面のモジュール分割と、Windowsの通常権限保存・専用窓を合わせました。下記の旧Windows試験対応から更新し、プロセス所有確認・既存利用権保護を保持します。一般保存は固定ローカルNTFSの同一性確認・ファイル同期・同一ドライブのwrite-through置換です。ディレクトリ内容の停電耐性は保証しません。統合後のWindows実機確認、本体反映、配布更新は未実施です。

- Windows向けブラウザ起動を試験的に追加しました（[PR #3](https://github.com/kieiken/project-hub/pull/3)、Ruai-3653 さん）。CLIの実行ファイル解決、Git Bash・Explorer・フォルダ選択、セットアップ/起動バッチ、改行設定を取り込みました。
- Mac/Linuxでは依頼ごとのPATHを使う従来のCLI起動方法を維持します。WindowsのCLI探索も依頼の環境を使います。
- Windowsの停止要求は、実行中のCLIだけに一度送ります。プロセス所有確認・停止完了確認と待ち指示の自動開始には未対応の制限があります。
- fsyncSync全体の差し替えを廃止し、Windowsではディレクトリ同期のみを呼び出し側で省きます。再オープンするファイルには書き込み可能なハンドルを使い、本物のファイル同期エラーは隠しません。
- Windowsの外部ターミナル用一時ファイルは乱数名・排他作成とし、起動失敗時にも削除します。Windows実機での修正版の検証は未実施です。
