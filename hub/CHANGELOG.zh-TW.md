# Project Hub 變更紀錄

[日本語](CHANGELOG.md) | 繁體中文

較新的版本在上方。每次更新都要讓 `package.json` 的 `version` 與本紀錄最上方版本一致，並由測試確認。
版本規則：大幅改寫提高第一碼，新增功能提高第二碼，修正問題提高第三碼。以下完整翻譯公開版自4.20.0起的歷史；歷史中的功能描述以當時版本為準。

## 4.70.0（2026-10-07）

- Mac 讀取檢查加入目前 Hub 工作區及明確選取的一個外部資料夾；引導至「檔案與資料夾」，檢查本身不修改檔案、AI 可寫範圍或正在執行的服務。

- 新增選取 Codex／Claude 會話的連結畫面；預設全部未選，先預覽數量、缺少的紀錄與注意事項，再只保存來源連結。原會話、程式碼與工作資料夾不搬移，不建立副本或 Hub 新任務。
- 從「外部會話」接續同一個原生會話 ID／thread ID，使用既有登入與權限，將新回合保存到原始歷史。支援批准、停止與避免重送；來源無法使用時不另開新會話。原 App 的畫面不保證即時刷新，重新開啟可讀取同一份紀錄。
- 提供不依賴 Hub 的 AI Session Exporter 函式庫、CLI 與本機網頁，只將明確選取的人與 AI 文字匯出為 JSON／Markdown。
- Hub 對話與終端機的可寫範圍限於實際工作資料夾及同專案台帳，Claude 使用 `acceptEdits`、Codex 使用 `workspace-write`，啟動時收斂舊設定的較廣權限。原始程式碼與參考資料夾不加入可寫範圍；連結原會話則保留原工具權限。

## 4.69.1（2026-10-07）
- 桌面版可拖曳左側欄分隔線調整寬度，並在目前瀏覽器記住設定；支援鍵盤調整與螢幕閱讀器，手機維持原有版面。

## 4.69.0（2026-10-07）
- 新增預設關閉的 Hub 自動更新，可用 `HUB_AUTO_UPDATE=1` 設定首次預設；每天最多檢查原作者 `kieiken/project-hub` 的 `main` 一次，保存檢查時間，重啟與手動檢查不繞過24小時限制。
- 新版先在隔離來源整合並補齊繁中，完整測試、公開檢查、編譯與簽章通過後才更新，保留舊 App；確認後透過指定 fork 分支提交翻譯 PR 回原作者，來源衝突或翻譯／驗證失敗時不切換，PR 傳送狀態另行顯示。
- 可選擇以 `HUB_STORAGE_GUARD` 在啟動前檢查資料磁碟，檢查失敗時停止，不回存預設位置。
- 修正 MCP 測試只計算設定區塊標題，避免專案資料夾名稱導致誤判。
- 新增繁體中文介面、伺服器訊息、AI 指示與 Mac 應用程式文字，透過 `HUB_LANG=zh-TW` 選擇，保留日文版與既有資料格式。
- 新增完整繁中 README、參與指南、第三方聲明、變更歷史、專案範本、虛構台帳與 Issue／PR 範本；更新已落後於現行版本的遠端操作與 ChatGPT 說明。
- 新增可包含服務程式與執行相依套件的 Mac 建置方式，支援指定應用程式、資料、快取與暫存位置；仍需要 Node.js 22 以上與已登入的 AI CLI。
- 修正外接磁碟檔案刪除：預設使用來源磁碟的 Finder 垃圾桶，避免跨磁碟移動失敗，保留既有紀錄與還原驗證。
- 刪除中途失敗時新增「重新確認刪除內容」，重新取得刪除預覽與確認；已移動項目仍保留還原入口。
- 設定頁更新狀態並重繪時保留原本的捲動位置，避免操作中跳回頁面上方。
