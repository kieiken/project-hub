# Project Hub 變更紀錄

[日本語](CHANGELOG.md) | 繁體中文

較新的版本在上方。每次更新都要讓 `package.json` 的 `version` 與本紀錄最上方版本一致，並由測試確認。
版本規則：大幅改寫提高第一碼，新增功能提高第二碼，修正問題提高第三碼。以下完整翻譯公開版自4.20.0起的歷史；歷史中的功能描述以當時版本為準。

## 4.90.0（2026-10-08）

- 新增 macOS App CI；明確設定時將 Hub 程式同梱至 App。公開匯出包含繁中說明文件、範例、範本與 CI，並保留隱私檢查。
- 修正終端區結束提示與「建立」的繁中翻譯。

## 4.89.0（2026-10-08）

- 加入繁體中文版（`HUB_LANG=zh-TW`，未設定時為日文）。依最新程式碼重新接上翻譯，涵蓋 AI 帳號、使用量、freetalk、共用刪除保護、自動更新與 Markdown 表格。狀態與角色的儲存值、使用者文字、路徑、終端輸出及授權文字保留原文。
- 加入繁中說明、版本紀錄、範本與虛構範例。Mac App 與啟動設定傳遞語言，自動更新可辨識已安裝的翻譯辭典；自動翻譯仍須使用者開啟並設定來源、App、Storage Guard 與 fork。

## 4.88.0（2026-10-08）

- 在啟動、設定、App 建置與更新前執行選配的 Storage Guard；失敗時停止，不切換至其他磁碟。
- 加入預設關閉的自動更新。上游確認與翻譯嘗試使用永久保存的 24 小時閘門，包含手動要求、失敗與重啟；AI、排隊、整理與 GitHub 操作結束前不套用。
- 在隔離來源完成整合、全測試、App 建置、簽章與公開檔案確認後，保留舊 App 備份並替換；失敗或中斷可從保存的紀錄復原。
- 加入本機 Codex（GPT-6.1-Sol）自動翻譯與 gh 翻譯 PR 機制。翻譯辭典由後續繁中移植提供；缺少來源、App 或 Storage Guard 時顯示尚未支援。
- 保留 PR#1 A：外接磁碟使用原磁碟垃圾桶、設定頁保持捲動位置，以及 MCP 與磁碟垃圾桶測試修正。接回最新本體歷史並保留表格顯示。
