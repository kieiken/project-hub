**一般公開Beta版です。開発中の版です（v4.125.1）。** 機能・画面・保存の形は、これからも変わります。大事なデータでは使わず、試せる範囲で使ってください。使ってみた感想、不具合の報告、Pull Request を歓迎します。送り方は [CONTRIBUTING.md](CONTRIBUTING.md) を見てください。

プロジェクトと作業を一覧にして、画面の中で Claude Code / Codex を動かす管理ソフトです。1人で使う Mac、または試用版の Windows 11 x64 で使います。待ち受けるのは `127.0.0.1` だけで、利用者の認証はありません。Web サービスや共有サーバーとしては使えません。

使う前に、[hub/README.md](hub/README.md) の「使う前に知っておくこと」を読んでください。

## 前提

- macOS。Windows 11 x64 の試用は、下の「Windows 版」を参照してください
- Node.js 22 以上、Git
- 使う AI の CLI（Claude Code / Codex / GeminiのAgy CLI）を入れて、ログインしておく
- 作業画面の部品（node-pty）とアプリ（Project Hub.app）を作るには、Apple の開発ツールが必要

## はじめる（Mac）

取得したフォルダの一番上（この README がある所）で、次を実行します。

```
bash hub/setup.sh
```

- `~/Documents/AI-Workspace/` に `_hub/`・`Product/`・`Work/` を作ります。場所は `HUB_ROOT` で変えられます
- 何度実行しても大丈夫です。すでにある `roles.yaml` と台帳（`PROJECT.md` があるフォルダ）は触りません
- npm で node-pty を入れ、デスクトップに Project Hub.app を作ります

設定のAIアカウントにGemini（既定のみ）とChatGPTを表示します。役割分担ではログイン済みのClaude Code・Codex・Geminiを選べます（ChatGPTを除く）。

使い方・更新のしかたは [hub/README.md](hub/README.md) を見てください。

## Windows 版（限定試用）

Windows 11 x64 向けに、ブラウザで開く方法と、WebView2 を使う未署名の専用窓を用意しています。準備と起動の手順は [Windows 専用窓の案内](hub/app/windows/README.md) を読んでください。準備済みのフォルダでは `hub/start-window.cmd` で専用窓、`hub/start.cmd` でブラウザ版を開きます。普通の権限で使い、管理者として起動しないでください。Mac 用の `setup.sh` は使いません。

専用窓の起動、日本語の表示・保存、保存操作をしない再起動前後の比較、閉じる操作での通常終了を、Windows 実機で限定確認しています。全機能や実際の AI を使う動作の合格ではありません。利用権の保管は実装済みですが、本番の購入受付は準備中です。隔離実行・自動更新など、Windows で未対応の操作もあります。統合後の版でのWindows実機確認は別途必要です。

保存先は固定のローカル NTFS です。ファイルの書き込み確定と同じドライブ内の置き換えを使うため、管理者権限は不要です。ただし、ファイル名の変更や削除の直後に停電した時の確実さは、ドライブ全体の書き込み確定を使う以前の方式より弱くなる可能性があります。

専用窓の文字がぼやけるとの報告があり、表示品質は確認中です。確認済みの保存・終了の結果とは分けて扱っています。

## 注意

- **AI の許可確認**：既定では、Claude Code は許可確認を省き、Codex は許可確認とサンドボックスを省いて起動します。AI は利用者の権限でファイルを書き換えたり、コマンドを動かしたりできます。変える時は `_hub/roles.yaml` の `permissions` で指定します
- **料金**：AI の料金・プラン・課金のしかたは、各 CLI 側の設定に従います。Project Hub は料金がかからないことを保証しません
- 自動の Git 保存、作業用コピーに写す設定ファイル、手元に残る記録などの注意は [hub/README.md](hub/README.md) にあります

## 同梱の初期台帳（seed）

`hub/seed/` には、架空の「サンプルアプリ」「サンプルサイト」「サンプル文書」「Project Hub」の台帳が入っています。実際のプロジェクトや作業の記録ではありません。`setup.sh` はこれらを `Product/<名前>/` に写します。

## この公開物について

このフォルダは、Project Hub の部分だけを Git の履歴なしで切り出したものです。Git の作業コピーで `node scripts/export-public.js` を実行すると、コミット済みのファイルから `public-release/ProjectHub` に作り直せます。製品コードの版を固定する時は `--ref <コミット>`、公開用文書だけ別のコミットから使う時は `--public-ref <コミット>` を指定します。

- 実際の作業の記録（`.ai/` の会話・引き継ぎなど）は入っていません。ひな形と架空の台帳に必要な `.ai/` のファイルだけを入れています
- 公開版の [CHANGELOG](hub/CHANGELOG.md) は 4.20.0 から始まります（それより前の記録は過去の資料を含むため外しています）

## このBeta版で使えるもの（4.123.5）

プロジェクト・作業の［アイデア台帳］では、文章や画像に種類と扱いを選び［保存］できます。扱いは「記録だけ」が初期値で、「作る予定に入れる」を選んで保存した項目だけが制作の対象です。種類の変更・絞り込みにも対応します。会話の［台帳に残す］は1回で原文を残します。折りたたみの全体設定で既存の本作業コピーと検証方法を指定し、人が自動進行を開始します（初期無効）。質問への回答・一時停止・固定対象の確認と反映準備にも対応します。保存場所と導入・停止の条件は [アイデア帳の説明](docs/idea-ledger.md) を参照してください。

プロジェクトの会話で、待ち指示の［台帳へ退避］を押すと、本文・画像・元作業を記録だけで保存し、保存確認後にその指示だけを待ち列から外します。退避した項目から制作は始まりません。

一覧は行頭ラベル付きの1行表示で、新規項目は末尾へ追加します。［編集］からラベル変更・ドラッグでの並べ替え・完全削除ができます。削除は台帳が管理する本文・画像・履歴・保管控えを消し、元の会話と制作済みの変更は残します。

会話画面の［話し合い］で2〜4組のAI・モデルによる独立した意見、意見交換、まとめを順番に実行できます。各回は読み取り専用で、完了回数に基づく進捗と発言を同じ作業に保存します。利用上限の参加者はモデルを替えず不参加になり、保存済みの意見は手動でもまとめられます。初版の参加AIはClaude Code・Codexです。モデル候補はHubが確認した最新一覧を使います。

プロジェクト画面の［既存のGitHubに接続］で、ログイン済みアカウントから非公開リポジトリを検索・選択できます。本体内の製品フォルダに独立したGitがある場合は、そのフォルダを接続対象に選べます。接続は送り先の登録と表示だけで、内容や履歴の同期は行いません。別の送り先が登録済みの場合は上書きせずに止まります。

子作業の統合では［選ぶ］で対象を選び、［選別統合（件数）］で選んだ作業だけを取り込めます。各行［統合］と全件［一括統合］も使えます。［残さない］親の子孫は全て選ぶ必要があり、選んでいない作業は追加しません。

外部WebChatMCPを指定すると、Chat／ProへHubから自動で送り、GPT子に返答と作業結果を保存できます。初期は無効で、外部ソフトの導入・ログイン・実機確認が別途必要です。停止後は自動再送せず、手動Chatとアプリへのコピー経路は廃止しました。

メモ保管APIは、メモが新しい順に並んでいる前提で先頭の最近の行を残します。古い順のメモは対象外です。保管は確認後だけ行い、原文と既存の保管リンクを保持します。既存ファイルの通常POSIX権限はumaskに依存せず保持し、新規保管先と処理記録は0600で保存します。権限復元に失敗した場合は置き換えずに停止します。

- 子作業の成果を取り込んで続け、作業・会話・残件・コピーを保持できます。通常作業の［要約して続ける］は、一回の操作で要約・原文保管・会話切替まで進みます。整理結果の先頭に「次にする作業」を表示し、旧原文は履歴から読めます。

AIアカウントの切替と利用枠の表示、自由対話（freetalk）、共有する資料を保護する削除・復元、会話のMarkdown表表示を含みます。日本語と繁體中文に対応し、未設定は日本語、`HUB_LANG=zh-TW` で繁體中文になります。言語を切り替えても、利用者の文章・パス・端末出力・保存済みの状態や役割は元のままです。

Project Hubの自動更新は既定でオフです。利用にはGitソース・更新先App・ディスク確認の設定が必要で、ソースZIPや設定が揃わない環境では使えません。自動翻訳と翻訳PRの送信も明示設定が必要です。条件と設定方法は [hub/README.md](hub/README.md#project-hub-の自動更新) を見てください。

Mac AppのCIは、両言語の試験・公開検査・ビルド・署名確認を行い、繁體中文の配布用Appを作る構成です。Appは自己署名で、公証は行っていません。起動にはNode.js 22以上と利用するAI CLIが別途必要です。

ChatGPT の手動Chat・アプリへのコピー経路は廃止しました。Chat／ProはHubから自動送信し、GPT専用子へ返答と成果を保存します。MCPの共有実作業許可は維持します。

取り込み後、［アプリを作り直す］が表示されたら押し、案内に従ってアプリを開き直してください。横のChatGPTパネルは廃止しました。
